# ui-design/

Historique des prompts Figma Make utilisés pour générer les mockups
(dans l'ordre approximatif d'itération) :

1. `rh-entreprise-design.md` — brief de conception initial (palette,
   typographie, écrans à livrer, ton/rédaction).
2. `auth-screen.md` — premier lot de corrections/écrans ajoutés.
3. `design-system-specs.md` — deuxième lot (départements, transfert
   employé, recherche, cartes en lot, jours fériés, workflow départ...).
4. `figma-prompt-addendum.md` — addendum Blocs A-D (suivi CDD,
   délégation, notifications in-app, journal d'audit).
5. `design-tokens-color.md` — dernier addendum (token Rose Marque,
   écran Départements affiné).

`theme.css` / `fonts.css` : valeurs réelles de tokens (couleurs,
typographie, radius) extraites du fichier Figma — source de
`Mentora-managment-fe/src/app/theme.ts`.

**Statut de cette doc : référence UX/copy, pas la source de vérité des
exigences.** En cas de désaccord avec `01-requirements.md` (codes
EF-*/NFR-*), `01-requirements.md` fait foi — ces fichiers précisent le
*comment* (libellés, messages, comportement d'écran), pas le *quoi*.
